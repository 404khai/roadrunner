## 4. Target and scientific hypothesis

Predict whole-started-road-leg synthetic logical elapsed seconds at original
start. The hypothesis is that static start features could explain a systematic
residual if supported by the source. The controlled no-delay experiment is a null
check; no useful residual is expected. Scripted future delays in existing data
are not legitimate predictors or physical measurements. No edge or counterfactual
supervision, unchosen-path accuracy, learned routing gain or causal effect claimed.

## 5. Implementation

Rust `roadrunner-dataset::learned::export_research` and
`roadrunner learned export DATASET` fully verify retained source evidence and
export restricted requests. `ml/eta_engine.py` provides deterministic fitting,
whole-route inference, coverage/comparison reporting, immutable publication,
standalone verification and a bound-request prediction command. There are no
new Rust dependencies or third-party Python dependencies.

## 6. Model and numeric semantics

A fixed ridge residual regression uses two standardized features and one
intercept, with lambda 1 including the intercept penalty. Cholesky solves the
three-variable system. Python binary64, `math.fsum`, no randomization, no BLAS,
no neural architecture or tuning. The signed contract explicitly permits a
simple fitted correction; complexity is not a completion requirement.

## 7. Point-in-time input boundary

Numeric inputs are only original B0 seconds and original route distance meters.
Pinned directed route/context, original start reference, start revision and
availability witness remain recoverable metadata. Identity, family, seed, scenario,
policy, intervention, label and future state never enter the vector. The predictor
has no label argument. Archive loss is not turned into a missingness predictor.
